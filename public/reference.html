Connect your app.

One local API for your connected school AI sources. Start with an app key, find a verified model, then send a request.

  1. Create an app key. In Sources → App API keys, create a key for your app. This is separate from the dashboard token.
  2. Set your base URL. Use http://localhost:4000/v1 in compatible clients. Keep the gateway running.
  3. Choose a verified model. Call GET /v1/models and copy an ID whose endpoints include the route you need. An empty list means you need to connect and verify a source first.

Examples use placeholders, not your credentials. Copy them into your local terminal and replace the key and model ID. Requests consume the selected source’s allowance.

Understand an error

HTTP failures return {"error":{"message":"…","type":"…"}}. Streaming can start with HTTP 200 and fail later: inspect error events before treating a request as successful.

400 / 415
Check required fields, Content-Type and provider-specific restrictions.
401
Use a valid app key in the Bearer header. The dashboard token is not an app key.
403 / 404
Choose a verified model and endpoint from the catalog. Cross-origin browser access is blocked.
413
Reduce your upload. JSON is limited to 2 MiB; multipart and JSON image edits to 26 MiB.
429
Wait for quota or concurrency to reset. Gemini serves one request at a time.
500 / 502 / 503 / 504
Check the source connection and refresh the catalog. The upstream may be unavailable or have timed out.

Up to 16 active requests/sessions. Most HTTP inference times out after two minutes; images after five minutes. Realtime sessions last up to 15 minutes. Uploads stay in memory; usage logs do not store prompts or replies.

Need machine-readable schemas? Download the OpenAPI 3.1 contract for an API client or code-generation tool. The realtime entry documents its handshake; WebSocket events are described separately.
